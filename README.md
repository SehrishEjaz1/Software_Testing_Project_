# Software Testing — Katalon Studio Project
**Course:** Software Testing | FAST NUCES Lahore

## Overview
Automated Web UI functional testing of a login workflow using Katalon Studio.
Tested on: [Katalon Demo App](https://katalon-demo-cura.herokuapp.com/)

## Test Types
- Positive & Negative Test Cases
- Equivalence Partitioning (EP) & Boundary Value Analysis (BVA)
- Data-Driven Testing (Excel/CSV input)

## Tools Used
- **Primary:** Katalon Studio (Free Edition)
- **Fallback:** Selenium WebDriver
- **Browsers:** Chrome, Edge
- **CI/CD:** Jenkins, GitHub Actions

## Key Features Tested
- Login workflow validation
- Invalid credential error handling
- Successful navigation after login
